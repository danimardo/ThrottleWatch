# Informe de mutation testing de L13

Fecha: 2026-09-19
Alcance: `apps/desktop/src-tauri/src/diagnostics/potential.rs` y `classifier.rs`
Herramienta: `cargo-mutants 27.1.0` con `nextest` y perfil `ci`

## Ejecución

La línea base dirigida pasó con:

```text
cargo nextest run --locked --profile ci --no-tests=pass diagnostics::
26/26 pruebas, código 0
```

La ejecución completa se repartió en cuatro shards para evitar copiar el `target` de Tauri:

```text
cargo mutants --in-place --file src/diagnostics/potential.rs --file src/diagnostics/classifier.rs \
  --test-tool nextest --baseline skip --timeout 60 --build-timeout 180 \
  --no-shuffle --shard N/4 --output target/mutants-l13-inplace-final-N \
  -- --profile ci diagnostics::
```

Los `outcomes.json` de `target/mutants-l13-inplace-final-{0..3}/mutants.out/` registran:

| Resultado | Total |
|---|---:|
| Mutantes generados | 124 |
| Capturados por las pruebas | 59 |
| Supervivientes | 60 |
| No viables | 5 |
| *Timeouts* | 0 |
| Errores de ejecución | 0 |

Tiempo acumulado de los cuatro shards: 56 min 30 s. La salida de cada shard y la lista íntegra
de supervivientes quedan en sus respectivos `mutants.out/missed.txt`; no se ha extrapolado ningún
resultado de los pilotos anteriores.

No se ha clasificado ningún superviviente como equivalente o código muerto: todos representan una
ruta o una aserción que el conjunto actual no observa. No se han añadido tests artificiales solo
para elevar el porcentaje; las ampliaciones quedan como deuda explícita para la siguiente pasada
selectiva sobre estos módulos. La línea base queda fijada en 59/124 mutantes capturados (sin
umbral de aceptación inicial, conforme a historias.md § 22).
